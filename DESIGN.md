# Design

Desain satu halaman yang responsif, bergaya Google-like: latar putih, teks abu lembut, aksen biru, kartu membulat, dan bayangan halus.

- Tab Hitung Harga dan Pesanan.
- Dropdown mobil dan type terhubung ke katalog.
- State kosong menampilkan panduan penggunaan.
- State sukses menampilkan ringkasan dalam kartu atau tabel.
- State error menampilkan pesan jelas di bawah form.
- Layout desktop memakai panel lebar; mobile memakai susunan satu kolom.
