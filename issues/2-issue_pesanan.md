# Deskripsi
Implementasi pesanan berisi beberapa mobil, validasi stok gabungan, dan tabel hasil.

# Tugas
- Tambahkan validasi dan fungsi `buat_pesanan`.
- Tambahkan endpoint `POST /api/pesanan`.
- Hubungkan tab Pesanan pada halaman.

# Kriteria Penerimaan
- Mengikuti test case pesanan pada SPEC.md.
- Duplicate varian dijumlahkan untuk cek stok.
- API mengembalikan HTTP 400 untuk pesanan tidak valid.

# Alur Kerja
issue -> branch -> test dulu -> implementasi -> commit -> pull request -> CI -> merge
